# Examples

Everything under `examples/` is **EXAMPLE material**: fixtures that
demonstrate and test the skill. Examples never define defaults, never act
as implicit assumptions, and the skill must work identically without them.
Real project files belong in the user's own repository
(see `/ukraine-electrical:init-project`).

| Directory | Scenario |
|---|---|
| `small-single-phase-apartment/` | Worked greenfield design: input + full output showing labels, citations, conflict surfacing, UNRESOLVED handling |
| `three-phase-balancing/` | Deterministic phase-balancer fixture with expected output |
| `incomplete-input/` | Minimal input; documents required incremental/UNRESOLVED behavior |
